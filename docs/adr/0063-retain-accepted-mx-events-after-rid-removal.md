# Retain accepted MX events after RID removal

Removing a RID from the RID Authorization Set immediately stops future collection and excludes that RID's history from new research snapshots, but it does not delete or hide Accepted MX Events already stored. An Agent version that still requires the removed RID Feed is blocked, together with only its dependent Teams, until the owner restores authorization or publishes a new Agent version without that Feed; the Engine never supplies retained history or silently narrows the declared input. The MX information view marks retained events as belonging to a currently unauthorized RID, and destructive removal, if ever needed, must be a separate explicit and auditable workflow so an ordinary authorization edit cannot erase collection history.
