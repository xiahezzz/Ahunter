# Publish one independent report per Team

Each Research Cycle will publish `cycle.json` for Snapshot provenance and lifecycle state, a navigation-only `index.md`, and a separate versioned directory for every selected Team. A successful Team directory contains its own `conclusion.json` and `report.md`; a blocked Team records only its own failure status and cannot publish a conclusion. The Cycle Index may list Team identities, statuses, and file locations but cannot quote, interpret, combine, or compare their conclusions. No cross-Team comparison files are produced.
