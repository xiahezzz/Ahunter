# Show normalized MX information without raw payloads

The MX Information View lists every Accepted MX Event through user-friendly normalized text, safe structured content, downloaded media, RID, timestamps, and opaque provenance identifiers, including retained history from RIDs no longer authorized. Its WebUI interface never returns raw payloads, original media URLs, credentials, tokens, cookies, or Chrome debugging identifiers; lower-level diagnosis remains a separate local workflow, trading inline forensic convenience for a consistently safe operator surface.
