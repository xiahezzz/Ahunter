# Order all Team Reports chronologically

The Local Operator Console will not define a home-page Market Team, primary Team, or separate market-overview report surface. Every published Team Report appears in the shared Research Report Explorer ordered by publication time from newest to oldest. Team identity and exact version remain filters and row metadata rather than deciding which report receives a privileged home-page position. This supersedes ADR-0096's home-page projection.
