# Use one fixed Decision Pipeline per Research Scope

A Hunter will own one fixed Market Decision Pipeline for every Market Team and one fixed Security Decision Pipeline for every Security Team; Team Manifests cannot select or customize either pipeline. ADR-0003's single cross-Scope pipeline is superseded because a whole-market subject and one Market Security require incompatible synthesis and conclusion contracts, while per-Team pipelines remain rejected because they would confound membership effects and multiply validation rules.
