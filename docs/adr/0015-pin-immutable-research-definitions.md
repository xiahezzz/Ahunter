# Pin immutable research definitions by version

Agent Manifests and Team Manifests become immutable once used by a Research Cycle. A Team Manifest pins every member as an exact Agent identity and version; changing membership or upgrading any member creates a new Team version. A material change to an Agent's instructions, input requirements, or output contract creates a new Agent version rather than mutating the existing declaration. Used definitions may be deprecated but not edited or deleted. Every Research Cycle records the exact Team, Agent, Data Product, Decision Pipeline, and Codex Execution Policy versions used, while all Teams in that Cycle continue to share the same pipeline and execution-policy versions.
