# Retain all LAgent version test records

The evolution tree and mean-return comparisons require the complete test history of every version, including failed, blocked, cancelled, and repeated tests. Keep each test's configuration, lifecycle, recorded outcomes, costs, and decision provenance permanently, with reruns creating new linked records and corrections appended rather than overwriting history. This incurs durable storage obligations but prevents success-only reporting, preserves rejected branches for later investigation, and makes every aggregate and selection traceable to the records it used.
