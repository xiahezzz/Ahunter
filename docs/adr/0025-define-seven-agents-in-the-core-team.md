# Define seven Agents in the Core Team

The first self-contained release will define the Market, Social, News, Fundamentals, Policy, Hot Money, and Lockup specialists as seven independent A Hunter-owned Agent Manifests with matching Data Product dependencies. It will publish one initial `a_share_core@1` Team Manifest that pins all seven Agents. Multi-Team selection is supported by the Engine from the first release, but additional investment-style combinations will be introduced later through Team Manifests after the first report is validated. Quality checks, Bull and Bear reviews, Research Manager, Trader, risk reviews, and Portfolio Manager remain shared Decision Pipeline stages rather than selectable Team members.
