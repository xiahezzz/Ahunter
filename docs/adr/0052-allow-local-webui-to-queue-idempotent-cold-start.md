# 允许本地 WebUI 提交幂等冷启动意图

此前 ADR-0040 将首次冷启动的显式提交限定为 CLI。现在本地操作台需要提供可见的“启动五年同步”入口，因此 WebUI 可以作为第二个、受限的控制适配器。

WebUI 只调用无参数的 `POST /api/market-daily/cold-start`。该接口将同一个无日期、幂等的冷启动意图写入 `advisor.sqlite`，立即返回 Request 编号和队列状态；它不调用行情来源、不冻结目标交易日、不创建 Run，也不启动或停止任何服务。Market Daily Service 仍是唯一认领、验证和执行数据摄取的进程，并在其 21:00 边界决定是否开始工作。

页面初始加载、刷新和全部状态读取继续保持只读。按钮只在尚未提交冷启动的 `idle` 状态显示；已经排队、运行、部分完成或完整完成时，页面展示状态而不重复提交。这样既提供本地一键入口，也保留 SQLite 控制面的幂等性、可恢复性和服务所有权。
