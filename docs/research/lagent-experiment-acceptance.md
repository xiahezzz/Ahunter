# LAgent 实验模块首版验收清单

状态：实施验收清单，2026-09-09；核心规则见[设计定稿](lagent-experiment-final-design.md)，责任划分见[tickets](../tickets/lagent-experiments/README.md)。以下列出应验证的行为，并非测试通过记录；本轮没有执行历史回放或真实模型试验。

依据：[设计与已确认规则](lagent-inner-loop-evaluation-design.md)、[配置及模块 Interface](lagent-experiment-contracts.md)。首版交付内层实验平台、手工候选比较、自动基线晋级和进化树；自动生成候选的外层 optimizer 后续接入。

## 配置与实验身份

| 场景 | 必须观察到的结果 |
| --- | --- |
| 改变金额、日期、交易日数、阶段时间或模型/执行参数 | 由配置生效；保留原始配置、生效值及来源，无代码中的隐式业务数值覆盖 |
| 起止日期与交易日数两种输入 | 选定一种为输入，经版本化日历派生同一实际日期列表；冲突或缺失日历有明确错误 |
| 必需参数未填写或选中不支持的账户/数据能力 | 草案可保留，正式预检拒绝并说明缺失项，不暗中降级 |
| 封存候选后修改代码或平台规则 | 不能改变原运行；分别形成新候选或新实验定义，保存内容身份 |
| 初始资金与研究成本 | 账户资金、交易费用、研究成本分别核算；研究费用不默认从本金扣减 |

## 时间与信息

| 场景 | 必须观察到的结果 |
| --- | --- |
| 竞价成交前研究 | 所有主/子任务使用较早固定快照，无法读取最终竞价结果；买卖单按可用资源校验 |
| 竞价后研究 | 只在结果及自身回执按规则可见后提供；实际净回款可用才进入购买力，新单不能倒回开盘竞价 |
| 模型等待、重试或宿主跨过午夜 | 实际耗时计量，但不推进该阶段模拟时钟或扩展信息截点 |
| 09:30 至 23:00 的消息、成交或撤单回执 | 不调用主/子模型；只执行已接受指令，回执留待下一允许阶段供 agent 读取 |
| 只有日期的搜索服务 | 平台发送与截点匹配的历史日期条件，采用已确认的次日可见规则；信任服务筛选并记录参数，不要求逐页存档证明 |
| 自有行情交易日期与采集日期不同 | 保留各字段并使用产品声明的可用时间规则；不把完整日 K 提前放进当天盘前，也不伪造采集日期 |
| 独立测试、其他候选或隐藏任务记录 | 不通过上下文、trace 查询或缓存向内层提供未来结果或跨 Episode 记忆 |

## 计划与模拟执行

| 场景 | 必须观察到的结果 |
| --- | --- |
| 同份计划有非法指令或整批资源不足 | 整份拒绝，不留下部分委托/冻结；允许在同阶段预算内修正 |
| 卖单尚未成交 | 预计回款不参与买单校验；同阶段已有可用信用按所选账户规则处理 |
| 竞价部分成交 | 只计实际成交与可用净回款，剩余旧单及资源占用不因阶段转换消失 |
| 竞价后新计划失败 | 不撤回前一阶段已发生的成交或已接受指令 |
| 涨停、临界触价、排队或分钟内先后不明 | 按固定成交模型及所需证据判断；价格触及或容量上限不等于保证成交，必要证据缺失保留质量失败 |
| 多笔订单和撤换共用同一时段流动性 | 不重复分配可用成交容量，限价和新单生效后的成交机会约束生效 |
| 撤单请求先接收、交易所稍后确认 | 确认前资源仍被占用，期间成交有效；撤销只能作用于剩余数量 |
| 受限撤换 | 新价格及目标盘前固定；撤单确认后扣除旧单累计成交量，重新校验并提交；不重用旧排队优先级或盘中调用模型 |
| 撤换资源不足、旧单先全成或申报不合法 | 不擅改价格或缩量，分别保留未执行原因；已达目标不继续重挂 |
| 当日结束与期末计价 | DAY 剩余失效，不跨日续单；末日按收盘净值计分，持仓不伪造强平，盘后复盘不改分 |

## 故障、预算与恢复

| 情况 | 执行与计分政策 |
| --- | --- |
| 普通计划错误未修正 | 此前已接受指令继续，后续阶段可研究；完整期间合格则按实际收益计分，错误另记诊断 |
| 明确归因于候选自身的崩溃 | 阶段内恢复耗尽后结束该阶段；下阶段在预算允许时继续同版本和最后提交状态，完整期间合格则计分 |
| 研究预算耗尽 | 停止模型并丢弃未接受草稿，env 使用预留资源完成已有指令/撤换及原定期间；质量和成本合格才计分 |
| 模型服务、平台、必要数据、账本故障或归因不明 | 保留对应受阻/失败及证据，不假作候选零收益或正常不交易 |
| 崩溃发生在提交、释放或结算附近 | 从持久记录判定已完成的副作用，恢复不重复下单、释放、成交落账或成本结算 |
| 阶段关闭后的迟到模型结果 | 不能补入计划、修改时钟或创建盘中研究；保留尝试及丢弃原因 |
| 无法持久化必要执行记录 | 不继续产生无法追溯的新副作用；保留并报告恢复所需状态 |

候选缺陷归因必须有 runtime 退出/异常和宿主状态证据；不能仅因报错就认定是 LAgent 缺陷。手动取消不套用预算耗尽的正常计分政策。

## 比较、晋级与进化树

| 场景 | 必须观察到的结果 |
| --- | --- |
| 原定 08-03 至 08-07 反复调优 | 标为调优任务，允许外层使用反馈；不声称是未见最终评测 |
| 同版本的预定重复与多任务汇总 | 任务内平均、任务间按预设权重汇总，保留确切样本身份；无效样本不静默丢弃 |
| 复用基线已有测试 | 只引用同条件完整合格的原记录，不增加样本数或重复累计成本 |
| 从淘汰版本分叉 | 旧历史保留，新子版本独立测试；晋级比较当前基线而非仅比较父版本 |
| 候选满足预设晋级条件 | 自动更新实验基线并记录依据；不改运行中的候选或业务配置 |
| 多候选先后完成、基线已经变化 | 旧比较不覆盖新基线，重新比较当前基线后才可选择 |
| 重跑、更正、重新评分或隐藏树分支 | 原记录始终可查，新增关联记录；不覆盖成绩、不删失败，不把同一测试伪装为新测试 |
| 查询任意节点 | 可追溯父版本、分叉假设、全部测试/尝试、输入配置、数据截点、成本、错误、比较及晋级原因 |

## 验证层次与交付证据

先用可控样例验证时序、账本、资源竞争和恢复；这些样例不作为历史收益证据。随后用真实来源完成数据/搜索与时间语义预检，最后才用选定模型执行真实历史 Episode，并以相同契约完成候选比较。

交付时应提供：生效实验配置、数据预检结果、模型与成本计量记录、测试及产物身份、可审计模拟账本、比较/晋级记录和进化树入口。未通过项明确列出，不以界面已有或样例测试通过代替真实历史执行成功。

搜索服务、账户制度、阶段时刻、成交/估值、标定公式、重复与晋级、验证/留出预设均已由定稿 D01～D12 确定。运行前仍须交付真实数据与规则费率包、搜索连接、模型费用能力及真实标定结果，不能把 fixture 中的占位输入当作完成证据。

## 定稿补充验收与责任

| 场景 | 必须观察到的结果 | 责任 |
| --- | --- | --- |
| 原例预设和不同天数/金额 | 默认解析与定稿一致，每个数值有单位、范围和来源，无固定五日分支 | LE-001 |
| 09:25 事件界限与 09:25:05 快照 | 只纳入已公开竞价和可见回执；09:25 后新新闻不可用；必要结果迟到为质量失败 | LE-004/005 |
| 日期服务与无日期结果 | 日期参数由宿主注入，信任标签不冒充时间已验证；无连接明确 blocked | LE-004 |
| 佣金、部分成交、企业行动 | 最低佣金按整单累计，净回款不高估；股息/送转与原始价格估值不重复补偿 | LE-006 |
| 分钟/队列路由及容量 | 不完整分钟不回填，普通保守 no_fill 与必要证据缺失分开；共享容量不重复 | LE-007 |
| 阶段重复成功提交 | 同 plan_id 幂等；成功计划封闭该阶段；拒绝仍可修正重提 | LE-007/010 |
| 真实硬成本能力不支持 | cost_capability_missing 阻断正式比较，不能用未知账单或订阅免费取代计量 | LE-009 |
| 标定与预留 | 三次 calibration 不进入晋级样本；公式及 E 包络冻结，留出不按表现重新标定 | LE-009/015 |
| lease 丢失与未知外部调用 | 旧 worker 被 fence，未知结果先核对不盲重发；资金/费用恰好一次落账 | LE-002/010 |
| 默认晋级门槛 | 验证平均改善至少 10bp，2/3 配对为正，最差差值不低于 -1pp；门槛可配，缺样本 inconclusive | LE-011 |
| 留出暴露与不同任务长度 | 暴露永久记录，默认按长度分组；调优分不冒充正式验证或最终未见成绩 | LE-011/015 |
| 树中的重复内容及失败节点 | 提案与包身份分开，全部测试保留，来源和对手真实，不重复样本或费用 | LE-002/013 |

LE-014 汇总离线验收证据；LE-015 才交付真实运行报告。表中的数字是定稿默认，不代表已经发生的测试结果。
