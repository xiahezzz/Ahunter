# LAgent 模拟账户与费用契约

2026-09-09：LE-006 in_progress。已完成账户/费用基础与无企业行动时的原始收盘估值。
企业行动状态机及实际历史法定费用验收尚未完成；当前不提供正式评分或运行入口。

## 隔离账本与资金制度

`SimulatedAccount` 仅使用本 Test 的 experiment events/account projection，复用 worker
lease、同动作幂等、投影 revision、事务与事件重建。不会写生产 ledger_transactions
或 positions。资金政策固定 cash_equity_v1，未知政策/融资额度和未提供计息规则的非零
利息明确不支持。研究成本记录不进入交易现金。

状态保存 cash lots、证券 lots、订单资源、等待回执的释放额、应收、应付、负债及累计
已计费用。买入 lots 的可卖日期、卖出 cash lots 的可用/可取日期来自当期规则和同一
日历证据；结算所需后续交易日缺失会阻断，不能自己补工作日。

cash_equity_v1 的现金消耗约定：优先净额使用已确认、可再次买入但尚不可取的当日回款，
再消耗其他可用现金。该约定已写入实现；它是模拟政策，不代表用户券商的实际可取余额
算法，正式规则审查仍需覆盖这项约定。模型/外层候选不能自行修改政策。

## 冻结、部分成交与回执

整批订单先在独立状态副本中验证并冻结，再单事务提交。买单冻结限价名义金额和最大
适用费用；卖单冻结已确认可卖证券。独立新买单不能使用同计划预计卖款、取消请求或
未到可卖日期的买入证券；资源不足拒绝整批，已生效历史状态不回滚。

买入成交按实际金额及累计费用差额扣现金，保留未成交部分最大费用。价差/费用预留
释放额在回执前继续冻结。卖出成交只生成实际净回款，并按回执及规则日期控制可用和
可取。极小首笔成交不足以支付最低佣金时，差额记应付；不会生成负现金或融资额度，
可用资金继续扣除应付。后续可用现金可通过显式应付结清事件支付，不重复计费。

cancel_request 不释放旧资源，旧单仍可成交；只有取消确认、DAY 到期或拒绝终态才释放。
账户模块接受宿主执行引擎已证明的这些事实，不自行判定成交/撤单先后或市场合法申报量。
LE-007 将负责市场规则验证、执行证据、替换依赖及与整份阶段计划的原子接入。

实际财务状态按成交事件记账。给研究端的账户快照则要求事件截止与累计回执可用时间
同时满足，避免提前看到成交后余额或持仓。`observe(Boundary)` 与 LE-004/005 使用同样
两个界限；宿主仍需通过当前 PhaseSession 发放访问权限。

## 费用规则

`OrderFees` 使用传入 FeeSchedule 的生效日期、市场、法定条目和来源引用；缺少印花税/
过户费条目、区间不适用、重复计费或佣金包含关系矛盾时失败。没有内置当前法定税率。
测试费率均来自标明 synthetic fixture 的包，不能当作真实法规验收。

券商佣金使用 sealed execution 的模拟假设：原预设 0.0003、最低 5 CNY。每个有成交的
订单按累计成交额计算总费用，本次只结算新旧总额差；零成交不收费，撤换产生的新单
独立适用最低费。佣金包含的经手/监管费不再重复计收。费用以 Decimal 到分 HALF_UP，
当前 cash_equity_v1 不支持其他费用金额精度，明确拒绝而非悄悄改参数。

## 回放与 NAV

宿主回放引擎提交 checkpoint 说明区间内事件已全部处理。封闭区间不能再补入更早或
同一时刻的成交；估值要求 account replay 已封闭至估值截止。期末日期必须是封存任务
的最后交易日，不减少持续天数。每日/期末截止由传入历史市场收盘规则确定。

NAV = 现金 + 原始收盘证券市值 + 合格应收 - 应付 - 负债。初始持仓按合格原始价格，
不以成本价替代；初始 NAV 必须为正。停牌允许使用最近合格旧收盘，明确 stale_valuation，
不强平。复权价格、未来价格、非收盘事件、规则缺失、企业行动覆盖未知都拒绝。

估值保存引用的账户事件序号、状态哈希、证据输入哈希与永久 JSON 产物。net_return
只允许同 Test 的 initial/terminal 估值，按 NAV_end/NAV_start-1 计算；输出明确
formal_ready=false，仍须完整 Episode 数据/执行/成本验收，不能直接作为正式 Comparison。

## 企业行动与股息税

`CorporateActions` 接受宿主封存的发行人条款、历史税务政策、来源引用/哈希及可用时间。
在登记日收盘按实际持仓记录权益，分红在除息前记录名义应收但 NAV 应收为零，避免与
含息原始股价重复计值；除息时转为独立应收，到账时转现金。不能用未来条款补登记。

普通公开市场股票的税期按自然月/年计算，实际卖出按 FIFO 分配税务批次；即使后提交
委托先成交，也先消耗较早持仓并重分配其他委托的冻结批次。取得序号保留同日先后。
未卖出部分使用当前仍可适用的最高税率预留负债；每个账户事件/checkpoint 更新，不能
选用未来卖出日期降低预留。派息后卖出从净回款扣税；派息前卖出形成待派息应付，
普通应付结清不能提前扣这部分，到账时从股息扣除。分录、税额与批次变化同事务提交。

税率、适用区间与来源必须显式输入，零税率允许，过期政策阻止记账；没有内置真实
政策包。规则核对参考[财税〔2015〕101号](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)：
普通公开市场股票分档有效税负为 20%/10%/超过一年免税，短期持有派息时暂不扣缴，
转让后计算税款。自然月/年与 FIFO 参考[税务机关操作解答](https://shanghai.chinatax.gov.cn/zcfw/zcjd/201211/t400944.html)；
该 2012 解答中的旧长期税率及初次预扣规则已被后续政策修改，未用于本实现。
实际登记结算扣款时间和日终净额批次仍需正式历史规则包验收，当前是逐事件模拟政策。

无应税基数的送转/拆股支持整数份额及明确可交易时点。`bonus.shares_ratio` 表示每旧股
新增份额，`split.shares_ratio` 表示每旧股最终份额倍数；来源适配器必须明确转换语义。
新股持有期继承或自生效日起算须明确声明。未完成旧 DAY 委托必须先终结。
自愿配股记录不参与，不扣认购款。停牌旧原始收盘按其后已生效的分红/送转/拆股调整，
当期原始收盘不重复调整；保存原价、估值价及逐项变换。遗漏已生效行动、未知行动或
未应用权益阻止 NAV。所有这些结果仍为 formal_ready=false。

## 特殊结算

`SpecialSettlements` 接受有来源包/可用时间的 `SettlementTerms`。执行时核对全部持仓
批次快照哈希及逐批旧股数量、现金对价、最终整数换股数量和成本承接；部分匹配失败
不生成任何注销或资产。来源适配器负责提供已核验的最终零碎股分配结果，执行器不猜
舍入方式或零碎股现金价。现金明确要求无条件固定债权；或有、可争议或金额未知对价
不属于这个合同。实际规则包验收仍未完成，调用参数不能自行构成正式来源资格。

有效时点一次性注销旧股，建立合格固定应收或替代证券。应收到账才可用现金，新股到
明确可交易时点才可卖；新证券必须有自身合格价格，不能用旧证券末价替代。纯换股承接
投资成本，混合对价成本分摊须显式给出；金额到分核对。注销后的证券不能再接收委托或
经后续换股重新出现。未终态订单、未应用的登记权益、来源未到可用时点都阻止注销。

税务处理必须显式选择：现金处置按原股息税义务结算并扣除可扣税额；纯换股可承接原
取得日期、剩余税基及对应新股单位；声明无义务时，账内若仍有未结税基则失败。混合
现金/换股的复杂税务分摊没有实现。结算固定对价不足以覆盖待扣税额时也明确失败。

现金到账、税额与换股均使用账户既有同键幂等、租约、单事务事件与重建机制，NAV 继续
按已有公式计量固定应收和新证券，不插入期末强平交易。
