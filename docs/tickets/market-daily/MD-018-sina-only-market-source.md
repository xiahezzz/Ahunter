# 将 Market Daily 收敛为新浪唯一行情源

## 结果

Market Daily 的股票清单、原始日 K、前复权因子、沪深交易日和缺失 K 线证据全部由仓库内同一个新浪适配器提供；运行时不再调用 Eastmoney、TDX 或交易所行情接口，也不需要数据源密钥。

## 范围

- 新增新浪日 K、前复权因子、沪深股票节点、指数交易日和停牌缺席适配能力。
- 股票节点先读取精确总数，再按新浪实际支持的每页 100 条完整分页；过滤北交所、CDR 与非普通沪深 A 股。
- 为全部新浪请求建立共享的每秒 2 次限流器；连接错误、HTTP 429 和 5xx 最多尝试 3 次，并有界遵守 `Retry-After`。
- 运行时使用单 Provider，不做来源回退；失败保留 `source_missing`，由后续补洞处理。
- 将历史日 K 缺失的成交额保存为 `NULL`，禁止填 0 或跨来源补字段。
- 将 CLI、preflight、交易日和股票池接线全部改成新浪单源。
- 将运行配置收敛为 `source: sina`，移除 `tdxpy` 基础运行依赖。

## 不包含

- 删除历史 Provider 源码或历史决策记录；它们不再接入实时运行路径。
- 提高并发、绕开限流、申请密钥或切换收费源。
- 完成耗时数小时的真实全市场冷启动；该实机验收继续由 MD-016 负责。

## 验收条件

- [x] 实际 live service wiring 只构造一个新浪适配器，并由所有 Market Daily 数据产品复用。
- [x] 新浪列表超过 100 条时完整分页，并对返回数量做精确校验。
- [x] 并发调用仍受共享的每秒 2 次固定间隔限制。
- [x] 429、5xx 和连接错误有界重试；失败后不调用任何备源。
- [x] 缺失成交额写入 `NULL`，缺失日 K 记录有来源证据的停牌缺席。
- [x] 项目运行配置和基础依赖中不再声明 Eastmoney、TDX 或主备源。
- [x] 固定 fixture 测试、完整 Market Daily 测试和真实新浪 preflight 通过。
