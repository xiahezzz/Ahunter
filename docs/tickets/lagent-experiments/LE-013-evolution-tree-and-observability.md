# 进化树、版本详情与运行可观测界面

## 结果

用户能看清 optimizer 或手工提案在哪些关键节点分叉、测了什么、为什么晋级或被淘汰，并追到每次原始记录。

设计依据：[实施设计定稿](../../research/lagent-experiment-final-design.md)（D11）。数值均来自可配置 preset，不在代码中另写隐藏默认。统一完成标准见[索引](README.md)。

## 依赖

[LE-012](LE-012-api-cli-and-skill.md)

## 范围

- 增加实验配置/详情、进化树、节点全测试列表、Comparison 和单 Episode 详情，复用现有本地研究 UI 和队列。
- 树节点为候选提案，标 parent、来源、hypothesis、diff、包哈希；单独标当前基线及历史选择，比较对手不误作父节点。
- 所有失败/blocked/cancelled/repeat/attempt 可查询，分页不丢历史；隐藏树节点只是视图过滤。
- 运行详情展示模拟阶段、现实耗时、主子任务、查询截点、usage/成本/预留、计划/成交/撤换/账户与质量原因。
- 可下钻从晋级到确切样本，从成交到证据及分录；隐藏评测访问在宿主视图层限制，查看行为记录 exposure。
- 空树、只有 preflight blocked、同内容新提案、从淘汰分支再分叉都正常展示，不伪造 optimizer 自动过程。

## 验收条件

- [ ] 包含成功/失败/取消分叉的 fixture 树全部可达；父版本与当前基线比较清楚。
- [ ] 每个版本全部测试永久可查，重复身份不累计为额外样本，复用成本不重复。
- [ ] 没有数据或真实模型运行时显示 blocked/未运行，不显示模拟收益占位值。
- [ ] 页面操作走同一 API；可通过键盘和列表访问节点，大树分页/展开不依赖一次加载全部 trace。

## 可能触点

frontend/src/research/ 下实验视图；现有 App 导航；实验 API 查询投影

## 验证

前端状态/交互测试及浏览器视觉检查，覆盖大树/无结果/错误/分页；不在产品界面展示私有思维链或实现内部日志替代用户说明。

## CLI / skill 影响

UI 新增操作必须已有对应 CLI，更新 skill 中从实验到 tree/trace 的查询流程。
