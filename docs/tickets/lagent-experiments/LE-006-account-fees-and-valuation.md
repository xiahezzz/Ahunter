# 模拟账户、费用与企业行动估值

## 结果

资金制度独立于本金和研究预算；订单资源、实际净回款与期末净值可从账本重建。

设计依据：[实施设计定稿](../../research/lagent-experiment-final-design.md)（D02, D05）。数值均来自可配置 preset，不在代码中另写隐藏默认。统一完成标准见[索引](README.md)。

## 依赖

[LE-001](LE-001-specification-and-contracts.md), [LE-002](LE-002-records-artifacts-and-idempotency.md), [LE-003](LE-003-historical-data-and-rule-bundles.md)

## 范围

- 实现 cash_equity_v1 与可扩展 policy 契约；资金制度在 env.account，未支持融资等政策明确拒绝。
- 建立现金/证券余额、可用、冻结、应收应付和负债分录；禁止未成交卖款、未确认撤单资源和未到期可卖证券被预支。
- 按限价及最大费用预留，部分成交增量结算；佣金每订单累计最低费，零成交不收费，撤换新单独立计费。
- 规则包解析法定费率，券商佣金假设与真实法规分开；Decimal 与到分取整，避免经手/监管费重复计收。
- 实现权益登记、分红应收/到账、股息税、送转股及可交易时点；自愿配股默认不参与。
- 按原始收盘估值，停牌沿最近合格价格并应用企业行动；特殊退市/合并数据不足阻断；末日不强平。

## 验收条件

- [ ] 竞价卖出部分成交只能使用已确认可用净款；买入当日可卖量服从制度。
- [ ] 买单最小费用、跨阶段部分成交、撤单确认和新单费用均不重复或透支。
- [ ] NAV 与分录重放一致，分红/送转不重复用复权补偿，研究费用不扣本金。
- [ ] 初始 200000 可改、空仓收益可为零、持仓期末计价正确；未知估值或费率不可默认为零。

## 可能触点

advisor/research/experiments/account.py；advisor/research/experiments/valuation.py（新增）；独立模拟账本表

经 env.account 使用的 Interface 检查资金守恒、冻结释放、部分成交、权益与末日 NAV，验证真实账本不被写入。
